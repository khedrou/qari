# قارئ الكتب

قارئ PDF كيتثبت كتطبيق. كيخدم بلا نت، ومكتبة pdf.js داخلو (ما كيعتمدش على CDN).

## النشر على GitHub Pages

1. دير repository جديد (مثلا `qari`) وخليه Public.
2. حمّل فيه كل محتوى هاد المجلد: `index.html` و`manifest.json` و`sw.js` والمجلدين `icons` و`lib`.
   - من PC: **Add file → Upload files** وجرّ الملفات والمجلدات.
   - 41 ملف كاملين، تحت الحد ديال GitHub (100 ملف ف المرة).
3. **Settings → Pages → Build and deployment**: Source = *Deploy from a branch*، Branch = `main` و `/ (root)`، وضغط **Save**.
4. من بعد دقيقة تقريبا، الرابط كيكون: `https://USERNAME.github.io/REPO/`
5. حل الرابط ف Chrome على التيليفون، ومن القائمة ⋮ اختار **Install app** (أو **Add to Home Screen**).

## ملاحظات

- خاص الرابط يكون HTTPS (GitHub Pages كيعطيه). فتح `index.html` مباشرة من الملفات ما غاديش يخدم.
- الخطوط (أميري، نسخ، القاهرة…) كتتحمل من Google أول مرة وكتبقى محفوظة. إيلا فتحتي التطبيق أول مرة بلا نت، كيستعمل خط النظام.
- الكتب لي كتفتح كتتحفظ ف تخزين التطبيق ف التيليفون. إيلا مسحتي بيانات الموقع من Chrome كتمسح.
- باش تحدّث التطبيق من بعد: بدّل الملفات ف GitHub، وبدّل `VERSION` ف `sw.js` (مثلا `qari-v2`). التيليفون كياخد النسخة الجديدة ف الفتحة الجاية.
